# Морзе 73 — самоучитель азбуки Морзе (PWA)

## Что это и для кого
Игра-самоучитель приёма и передачи морзянки на слух. Для **папы Кости** — радиолюбитель,
73 года, позывной **Boney M**, не айтишник. Принципы: простота и надёжность важнее функций,
крупный шрифт, без скрытых жестов, полностью офлайн, тёплый уважительный тон.

**Названия (решение Кости, 30 июля 2026):** приложение — **«Морзе 73» / «Morse 73»**
(понятно на обоих языках, цифры не требуют перевода). Маскот — дед в наушниках за ключом —
**Радист Боня / Bonya**. «Boney M» остаётся личным позывным папы, а не названием продукта.
Ключ `localStorage` (`boni_m_state`), имя репозитория и адрес Pages **намеренно не переименованы**:
это стёрло бы прогресс на телефоне папы и сломало уже установленное приложение.

Полное ТЗ — [`boni-m/TZ.md`](boni-m/TZ.md). Разбор/критика/план — [`PLAN.md`](PLAN.md).
Как на этом заработать — [`MONETIZATION.md`](MONETIZATION.md) (план, ничего не подключено).

## Технологии (жёстко)
Чистые HTML+CSS+JS, **без библиотек/фреймворков/CDN/сборщиков**. Звук — Web Audio (без файлов).
PWA с офлайном (service worker, cache-first). Прогресс — `localStorage` (`boni_m_state`),
с миграцией, резервной копией и `storage.persist()`. ES-модули, поэтому те же файлы из `app/js/`
тестируются в Node.

## Принятые решения (отличия от буквального ТЗ — согласованы с Костей)
1. **Позывной «Boney M» привязан к русскому треку** (а не к латинице). Коды Б,О,Н,Е,Ы,М = B,O,N,E,Y,M,
   поэтому спецдрилл доступен после освоения Ы (21-я буква), без английского режима.
2. **Цифры подмешиваются в общий поток «Учиться»** после 20 букв (без отдельного экрана).
3. **Хостинг — GitHub Pages** (авто-деплой `app/` через `.github/workflows/deploy.yml`).
4. Знаки препинания §3.4 приведены к **международному стандарту ITU M.1677** (поправлены
   3 кода против ТЗ: Точка/Запятая/Восклицание) — чтобы знания соответствовали признанным
   стандартам. Закреплено автотестом сверки с ITU в `test/data.test.js`.
5. **Монетизация — донаты первым шагом, реклама отклонена.** Разбор с цифрами и источниками
   в [`MONETIZATION.md`](MONETIZATION.md). Коротко: реклама требует сети (ломает офлайн),
   баннера согласия на cookie и либо сервера, либо публикации в сторах (Google Play: 25 $
   плюс 12 тестировщиков на 14 дней для новых личных аккаунтов), а приносит при этом мало —
   в приложении один-два показа за занятие, а не десятки, как на сайте. Донат — одна кнопка
   и ноль инфраструктуры. Наибольший рост даёт не способ оплаты, а английская версия
   интерфейса. Единственный честный кандидат на подписку — сетевой режим чата морзянкой,
   потому что у него есть постоянные расходы на сервер.
6. **«Ключ» — два режима** (переключатель сверху, выбор запоминается в `settings.keyMode`):
   «Тренировка» (как раньше — показывает букву, проверяет) и «Свободно» (набор слов/предложений
   с кнопками «Стереть»/«Очистить»). Пробел между словами — **авто по длинной паузе**, и
   **максимум один** между символами (правило в чистом модуле `app/js/keytext.js`, тест
   `test/keytext.test.js`). Также сделано ревью UX/UI ([`UX-REVIEW.md`](UX-REVIEW.md)):
   чистка иллюстраций от обрезков, читаемость, спокойный пейсинг «Верно!».

## Как запускать и тестировать
```bash
cd app && python3 -m http.server 8000   # посмотреть на компьютере → localhost:8000
npm test                                  # автотесты логики + проверка контраста тем
node test/smoke.mjs                       # дымовой тест интерфейса, чистая установка (JSDOM)
node test/smoke-upgrade.mjs               # дымовой тест ОБНОВЛЕНИЯ: старое состояние из телефона папы
node tools/screens.mjs                    # скриншоты всех экранов в обеих темах + проверка вёрстки и доступности
node tools/selfcheck.mjs                  # проверка самих проверок: ловят ли они нарушения
```
`test/smoke-upgrade.mjs` — обязателен при правках, затрагивающих состояние или вехи.
Обычный smoke стартует с чистого листа, а на телефоне папы лежит состояние прежней
сборки: без `lastFirst`, без `settings.theme`, с незаписанными вехами. Тест проверяет,
что прогресс не теряется и что заслуженные ранее вехи не выпадают поздравлением
посреди занятия.
`tools/screens.mjs` — обязательный шаг при правках оформления: JSDOM картинку не видит.
Он же ловит обрезанный текст, выход за край экрана, шрифт меньше 17px и кнопку ниже 44px.
Скриншоты складываются в `tools/screenshots/` (в git не попадают).

## Структура
- `app/` — само приложение (хостится). Контроллер — `app.js`, чистая логика — `app/js/*`.
- `test/` — автотесты логики (`*.test.js`) + дымовой тест UI (`smoke.mjs`).
- `boni-m/` — исходное ТЗ и мастер-PNG ассетов (герой). Рабочие WebP/иконки — в `app/assets/`.
